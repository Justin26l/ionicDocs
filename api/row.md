# ion-row

URL: https://ionicframework.com/docs/api/row

Version: v8
[shadow](/docs/reference/glossary#shadow)Rows are horizontal components of the [grid](/docs/api/grid) system and contain varying numbers of [columns](/docs/api/col) . They ensure the columns are positioned properly.

See the [grid](/docs/api/grid) documentation for more information.

## Row Alignment

By default, columns will stretch to fill the entire height of the row and wrap when necessary. Rows are [flex containers](https://developer.mozilla.org/en-US/docs/Glossary/Flex_Container) , so there are several [CSS classes](/docs/layout/css-utilities#flex-container-properties) that can be applied to a row to customize this behavior.
