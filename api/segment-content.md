# ion-segment-content

URL: https://ionicframework.com/docs/api/segment-content

Version: v8
[shadow](/docs/reference/glossary#shadow)Segment content is a wrapper element used to control the display of child elements when using swipeable segments. Segment content elements are children of a single [segment view](/docs/api/segment-view) instance that is linked to a [segment](/docs/api/segment) . See our [swipeable segments](/docs/api/segment#swipeable-segments) documentation for more information on how to use segment contents.

## Usage

Each `ion-segment-content` needs a unique `id` attribute. This will be used to link the segment content to a segment button via the button's [contentId property](/docs/api/segment-button#properties) .
