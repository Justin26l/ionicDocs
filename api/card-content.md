# ion-card-content

URL: https://ionicframework.com/docs/api/card-content

Version: v8
Card content is a child component of card that adds padding around its contents. It is recommended that any text content for a card should be placed inside of card content.

See the [Card](/docs/api/card) documentation for more information.

## Properties

### mode

| **Description** | The mode determines which platform styles to use.

This is a [virtual property](/docs/core-concepts/fundamentals#virtual-properties) that is set once during initialization and will not update if you change its value after the initial render.
