# ion-item-group

URL: https://ionicframework.com/docs/api/item-group

Version: v8
Item groups are containers that organize similar [items](/docs/api/item) together. They can contain [item dividers](/docs/api/item-divider) to divide the items into multiple sections. They can also be used to group [sliding items](/docs/api/item-sliding) .
