# ion-text

URL: https://ionicframework.com/docs/api/text

Version: v8
[shadow](/docs/reference/glossary#shadow)The text component is a simple component that can be used to style the text color of any element. The `ion-text` element should wrap the element in order to change the text color of that element.

## Basic Usage

## Theming

The text component can be customized by changing any of the default [colors](/docs/theming/colors) Ionic provides.
